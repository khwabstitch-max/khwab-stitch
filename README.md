# Khwab Stitch

Bespoke tailoring, custom design selection, and order management application for handcrafted garments.

## Features

- **Custom Tailoring Wizard**: Multi-step outfit and styling selection for Blouses, Kurtis, and Suits.
- **Visual Design Customizer**: Real-time previews of neckline designs, sleeve styles, and lengths.
- **Flexible Measurements**: Multiple options including self-measurement with visual diagrams, sample garment handling, and video call assistance.
- **Multi-Page Printable Receipts**: Clean order summaries with high-resolution slip printing and PDF export.
- **Atelier Management Portal**: Built-in order review, filtering, status tracking, and CSV export.

## Tech Stack

- **Frontend**: React 18, Vite, Tailwind CSS, Lucide Icons
- **Deployment Ready**: Vercel & Netlify compatible

## Getting Started

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
npm start
```
